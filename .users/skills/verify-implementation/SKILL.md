# 구현 검증

`.agents/skills/verify-implementation/SKILL.md`의 사람용 핵심 규칙입니다.

## 실행 원칙

1. 등록된 모든 `verify-*` 스킬을 순서대로 실행합니다.
2. 발견 사항마다 파일, 근거, 영향, 수정 방법을 기록합니다.
3. 명백한 범위 내 구현·테스트·문서 정합성 결함은 반복 승인 없이 자동 수정합니다.
4. 수정한 검사를 다시 실행해 수정 전·후 결과를 비교합니다.
5. 전체 검증 결과를 PASS 또는 FAIL로 보고합니다.

## 질문이 필요한 경우

다음 중 하나가 실제로 남은 경우에만 사용자 결정을 요청합니다.

- 새 설계·사업·제품 방향 선택
- 승인된 목표를 바꾸는 범위 확대
- 비가역 삭제 또는 외부 영향 예외
- 근거만으로 결정할 수 없는 중요한 선택

단순 결함 수정, 테스트 보강, 포맷·문법·미러 정합화, 이미 승인된 범위의 재검증은
`AskUserQuestion` 대상이 아닙니다.

## 완료 기준

- 수정 대상 검사가 재실행되어야 합니다.
- 자동 수정이 새 범위나 설계 결정을 만들지 않았는지 확인해야 합니다.
- 미해결 항목은 기술 결함과 사용자 결정 항목으로 구분해 보고해야 합니다.
