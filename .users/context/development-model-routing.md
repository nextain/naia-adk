# 개발 모델 배정

이 문서는 Alpha ADK 루트 협업 절차의 모델 배정 기준입니다. 가능한 경우 먼저 계약과 결정론적 검사를 수행하고, 범위가 정해진 일을 안전하게 처리할 수 있는 가장 저렴한 역할을 사용합니다. 위험도 또는 해결되지 않은 근거 부족이 있을 때만 상위 역할로 올립니다. 이 워크스페이스의 모델 배정에는 OpenCode와 HY3를 사용하지 않습니다.

## 범용 계약 계층

정본 규칙은 Codex나 Claude의 모델명이 아니라 `조정자·탐색자·설계자·구현자·테스터·독립 리뷰어·중재자·번역자`의 능력과 증거를 정의합니다. 특정 CLI 플래그와 모델명은 어댑터에만 둡니다. 따라서 다른 도구도 같은 역할 능력, 계약 범위, 동일 수정본 해시, 서로 다른 역할·세션·실행 ID, 실패 시 차단 조건을 충족하면 이 하네스를 사용할 수 있습니다.

모델 호출 전에는 결정론적 검사를 먼저 수행하고, 필요한 능력과 위험 수준을 만족하는 가장 저렴한 어댑터를 선택합니다. 필수 독립 역할을 제공할 어댑터가 없으면 셀프 체크로 대체하지 않고 차단합니다.

범용 역할은 어댑터에서 명시적으로 대응시킵니다. 구현자는 Codex의 worker에 연결하고, 번역은 Claude Haiku 4.5 → Codex GPT-5.6 Luna(low) → Claude Sonnet 순서의 저비용 fallback chain을 사용합니다. 모든 CLI 호출은 공용 stdin 기반 호출 함수를 사용하므로 긴 프롬프트를 명령행 인자로 전달하지 않습니다.

## Codex 어댑터

기본 조정자와 최종 통합 책임자는 Codex의 `gpt-5.6-sol`(중간 추론 수준)입니다. 계약 해석, 통합 결정, 최종 정리와 최종 파일 변경은 이 역할이 맡습니다.

| 업무 | 모델과 추론 수준 | 실행 범위 |
|---|---|---|
| 범위가 정해진 탐색, 컨텍스트 지도화, 근거 수집 | Codex Terra, 낮음 | 읽기 전용 |
| 승인된 범위의 구현 | Codex Terra, 중간 | 작업 공간 쓰기 허용 |
| 범위가 정해진 설계 대안 분석 | Codex Terra, 높음 | 읽기 전용 |
| 집중 테스트와 검증 근거 수집 | Codex Terra, 중간 | 작업 공간 쓰기 허용 |
| 수정본의 독립 적대 리뷰 | 가능하면 구현자와 다른 모델·공급자, 필수 패널은 Codex Terra, 높음 | 읽기 전용 |
| 고위험 통합 또는 미해결 리뷰 지적의 중재 | Codex Sol, 높음 | 읽기 전용 |

## Claude 어댑터

Claude는 특정 날짜가 붙은 오래된 모델 ID를 이 계약에 고정하지 않습니다. 설치된 Claude 설정에서 현재 지원하는 별칭 또는 모델명을 사용합니다.

- 경량 역할: 설치 설정이 지원할 때 기계적 분류, 번역 배치, 범위가 정해진 탐색에 사용합니다.
- 일반 역할: 설치 설정이 선택하는 일반 분석 또는 구현에 사용합니다.
- 상위 역할: 설계, 안전에 중요한 판단, 또는 해결되지 않은 리뷰 근거에만 사용합니다.

Claude 역시 같은 실행의 구현자와 적대 리뷰어를 겸할 수 없습니다.

## 독립 적대 리뷰

구현자의 셀프 체크는 유용하지만 적대 리뷰가 아닙니다. 적대 리뷰는 반드시 필요하며 가능한 경우 구현자와 다른 모델 또는 공급자를 우선합니다. 이 선호는 다음 필수 독립성 조건을 절대 완화하지 않습니다.

- `session_id`
- `execution_id`

리뷰어는 이전 또는 불명확한 상태가 아니라, 변경할 수 없는 같은 수정본 해시를 읽기 전용으로 검토합니다. 모든 변경은 수정본이 바뀌지 않은 상태에서 Codex Terra와 Claude Sonnet의 서로 독립적인 깨끗한 리뷰가 필요합니다. 로컬 영수증의 세션·실행 ID는 `.agents/progress/review-evidence/`에 보존한 원본 CLI 실행 기록에서 다시 계산하며 호출자가 적은 문자열만으로 인정하지 않습니다. 미해결 지적이 있을 때만 Sol 중재자가 근거를 판정합니다.

모든 리뷰 근거에는 계약 또는 요구사항 ID, 수정본 해시, 구현자와 리뷰어의 세션·실행 ID, 그리고 테스트 기록이 포함되어야 합니다.

로컬 훅은 Codex가 훅에 노출하는 도구 경로를 위한 결정론적 안전장치입니다. 모호한 셸 쓰기는 승인 계약에 정확한 명령 패턴이 없으면 차단합니다. 프로세스와 모델의 암호학적 진위를 보장하는 경계는 서명된 격리 리뷰 실행이며, 일반 진행 JSON이나 로컬 훅 파일이 그 수준의 진위를 보장한다고 주장하지 않습니다.

## 비용 통제

스키마, 해시, 미러, 인덱스, 기록 확인은 LLM을 호출하지 않는 결정론적 검사입니다. 번역과 기계적 분류는 변경된 입력만 해시 캐시와 함께 경량 모델 배치로 처리합니다. Sol의 높은 추론 수준은 중재 또는 실제 고위험 업무에만 사용합니다.
