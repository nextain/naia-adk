# 현재 업무 판

기존 [업무 장부](work-ledger.md)의 `진행 중` 항목만 역할별로 보여 줍니다. 대기·막힘·완료 항목은 제외합니다. 업무 내용, 기한과 마지막 갱신 시각은 장부에서 읽고, 목록 순서도 장부 순서를 따릅니다. 별도의 업무 정본이나 우선순위를 만들지 않습니다. 기존 장부에는 우선순위나 다음 행동 필드가 정해져 있지 않으므로 이를 추론하거나 표시하지 않습니다. 필요하다면 기존 행에 선택 필드를 정의한 뒤 장부 검증과 이 화면을 함께 확장할 수 있습니다. 데이터가 없으면 빈 판을 보여 주며, 장부가 잘못되거나 읽히지 않으면 오류를 보여 줍니다.

Node 22 이상에서 장부 경로를 명시해 실행합니다.

```sh
node scripts/work-now-board.mjs --ledger <비공개-work-ledger.yaml>
```

프로그램이 임의로 고른 로컬 주소와 사용자 이름, 실행 때마다 바뀌는 비밀번호를 출력합니다. 해당 주소를 브라우저에서 열고 출력된 인증 정보를 입력하세요. 페이지를 새로고침하면 장부를 다시 읽습니다. 같은 인증을 사용하는 `/api/work`는 현재 항목을 JSON으로 제공합니다. 사용을 마치면 프로세스를 종료하세요.

화면은 `127.0.0.1`에만 바인딩하며 외부 공개를 위한 인증 서비스가 아닙니다. 역방향 프록시나 외부망에 연결하지 말고, 인증 정보를 공유하지 마세요. 화면에는 업무 내용이 표시되므로 이를 볼 수 있는 사람만 장부와 실행 환경에 접근하도록 관리하세요. 브라우저 캐시를 방지하고, 장부의 지시 원문 링크와 결과 링크는 화면과 API에 넣지 않습니다. 기존 대시보드에 자동으로 연결하지 않습니다.
