# 결정 목록

대시보드의 **결정**에서 문서 출처 ID, 그 출처 안의 상대 경로, 대기 표와 완료 표의 마크다운 제목을 설정한다. 설정은 현재 브라우저에 저장되며 계정이나 다른 기기에 동기화되지 않는다. 문서는 기존 문서 읽기 권한을 그대로 따른다.

두 제목은 서로 달라야 하며 각 제목은 문서에 정확히 한 번 있어야 한다. 각 제목 아래 첫 마크다운 표를 읽는다. 표에는 `번호` 또는 `#` 열과 `무엇` 열을 둘 수 있다. 없는 경우 첫째 열과 둘째 열을 사용한다. 같은 수준 이상의 다음 제목에서 표 읽기가 끝난다. 항목을 누르면 원본 문서가 열린다.

문서나 제목을 찾지 못하거나 문서가 너무 크면 오류를 표시한다. 경로와 권한을 고친 뒤 다시 시도할 수 있다. 이 목록은 원본을 수정하거나 결정을 승인하지 않는다.
