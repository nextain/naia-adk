# Naia ADK 시작하기

이 작업 공간에서는 AI와 이야기하며 일합니다. 할 일을 사람에게 부탁하듯 말하면 AI가 회사 문서와 절차를 읽고 일을 합니다. 다른 기기나 다른 AI에게 넘길 일은 AI가 작업 대기열에 올리고, 사람이 봐야 할 문서가 생기면 AI가 "이 문서를 봐 주세요" 하고 확인을 요청합니다.

사람이 할 일은 세 가지입니다. AI에게 말로 맡기고, 브라우저의 대시보드에서 진행을 보고, AI가 봐 달라고 한 문서를 읽고 답합니다. 명령어를 외울 필요는 없습니다.

## 작업 공간의 모양

작업 공간은 naia-adk를 받은 폴더 하나입니다. 그 안에 두 가지를 더 받습니다.

- `data-company/` 아래에 회사 문서를 받습니다. 온보딩, 회사 소개, 업무 절차가 들어 있습니다.
- `projects/` 아래에 회사가 함께 쓰는 협업 프로젝트를 받습니다. 작업 대기열과 작업보드가 여기에 있습니다.

AI는 늘 맨 위 폴더(naia-adk를 받은 폴더)에서 띄웁니다. 그래야 AI가 회사 문서와 협업 프로젝트를 한꺼번에 보고, 작업 공간의 규칙을 따릅니다. `projects/` 안으로 들어가서 띄우지 않습니다.

## 처음 시작하기

사람이 준비할 것은 AI 도구 하나입니다. Claude Code나 Naia 앱을 설치하고, 회사 관리자에게 회사 문서 저장소 주소와 GitHub 조직 초대를 받아 둡니다.

1. 작업 공간을 받습니다. Naia 앱은 첫 설정 화면이 받아 줍니다. Claude Code를 쓰면 아무 폴더에서 띄운 뒤 "naia-adk를 받아서 내 비공개 저장소로 옮겨 줘"라고 하면 됩니다.
2. 받은 폴더(맨 위 폴더)에서 AI를 띄웁니다. Claude Code가 처음에 이 폴더를 신뢰하는지 물으면 신뢰한다고 답합니다. 그래야 AI가 준비 명령마다 승인을 묻지 않습니다. 그다음 이렇게 말합니다.

   > 시작하자. 회사 문서 저장소는 <받은 주소>야.

AI가 필요한 도구를 확인하고, 회사 문서와 협업 프로젝트를 받고, 대시보드를 띄운 뒤 브라우저 주소(`http://localhost:3142/docs`)를 알려 줍니다. 무언가 설치해야 하면 AI가 먼저 묻습니다.

## 매일 일하는 방법

### 하루 시작

맨 위 폴더에서 AI를 띄우고 "시작하자"라고 말합니다. AI가 최신 내용을 받고, 대시보드가 꺼져 있으면 띄워서 주소를 알려 줍니다.

대시보드에는 탭이 두 개 있습니다.

- "문서" 탭에서 회사 문서를 읽습니다. 온보딩, 회사 소개, 업무 절차가 여기에 있습니다.
- "작업" 탭에서 AI에게 맡긴 일이 어디까지 왔는지 봅니다. 화면은 "진행 중", "확인 필요", "최근 끝남" 세 칸으로 나뉩니다.

### AI에게 말로 맡기기

AI는 시작할 때 작업 공간의 규칙 파일을 스스로 읽기 때문에, 따로 설명하지 않아도 회사 절차를 압니다. 사람에게 부탁하듯 말하면 됩니다.

> 온보딩 문서를 읽고 내가 첫 주에 할 일을 정리해 줘.

> 이번 주 콘텐츠 기획을 같이 정하자. 정해지면 작업 대기열에 올려 줘.

> 어제 맡긴 일 어디까지 됐어?

일을 대기열에 올릴지, 다른 기기에 맡길지는 AI가 절차에 따라 판단하고 사람에게 묻습니다. 사람이 대기열 파일이나 명령을 직접 다룰 일은 없습니다.

### AI가 봐 달라고 한 문서 확인하기

AI는 사람이 정해야 하는 일이 생기면 그 내용을 문서로 정리하고 확인을 요청합니다. 요청은 작업 탭의 "확인 필요" 칸에 뜹니다. 카드의 "문서 보기"를 누르면 문서 탭에서 그 문서가 열립니다. 읽고 나서 AI에게 "이 문서 봤어, 이렇게 가자"처럼 말로 답하면 됩니다.

## 회사 관리자라면

대시보드에 어떤 회사 문서 폴더를 보여 줄지, 어떤 협업 프로젝트를 함께 받게 할지는 회사 문서 저장소의 `adk-company.json` 한 파일로 정합니다. 쓰는 법은 [회사 설정 파일 안내](company-config.ko.md)에 있습니다.

## 직접 명령으로 하고 싶다면

AI가 하는 일을 손으로 하려면 맨 위 폴더에서 다음을 실행합니다. Git, Node.js 22 이상, pnpm 9 이상이 필요합니다.

```bash
git clone https://github.com/nextain/naia-adk.git
cd naia-adk
git remote rename origin upstream
git remote add origin <내 비공개 저장소 주소>
git push -u origin main

pnpm install
pnpm adk:setup -- --company <회사 문서 저장소 주소>   # 처음 한 번
pnpm adk:setup -- --pull                             # 매일 최신 받기
./start.sh                                           # 대시보드 (Windows는 start.bat)
```

공개 ADK를 `upstream`으로 남겨 두는 까닭은 나중에 새 기능을 받아 오기 위해서입니다. 내 작업 기록과 회사 설정은 비공개 저장소(`origin`)에만 올라갑니다.
