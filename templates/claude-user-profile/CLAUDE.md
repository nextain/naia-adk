# 압축 요약 규칙 (naia-adk 공통 사용자 프로파일)

대화를 압축해 요약할 때 다음은 줄이지 않고 남긴다.

1. 지금 맡은 미션과 그 미션 문서 경로.
2. 사람(지시한 사람)의 원문 지시. 뜻만 옮기지 말고 글자 그대로, 언제 어느 채널에서 받았는지와 함께.
3. 아직 답하지 않은 질문과 약속한 끝 시각.
4. 작업 중인 파일·가지·커밋·결과 문서의 경로와 주소.
5. 하지 말라고 들은 것과 그 까닭.

요약에는 추측을 사실처럼 적지 않는다. 끝나지 않은 일을 끝났다고 적지 않는다.

압축 뒤 첫 행동: 미션 문서와 진행 기록 끝을 다시 읽고, 위 3번을 먼저 처리한다.
