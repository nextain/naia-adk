# 작업 산출물

제안서 폴더의 `draft/` 아래에 필요한 산출물만 만든다. 기존 프로젝트의 파일 규칙이 있으면 그 규칙을 우선한다.

## 양식 지도

| ID | 원본 항목 | 심사 질문 | 필요한 정보 | 관점 | 증빙 | 출처 후보 | 상태 |
|---|---|---|---|---|---|---|---|
| F-01 |  |  |  |  |  |  | 미확인 |

제출 자격, 마감, 분량, 파일 형식, 서명·날인, 증빙 목록도 문서 상단에 기록한다.

## 근거 장부

| ID | 사실·수치 | 상태 | 기준일 | 출처 경로·URL | 사용할 항목 | 충돌·주의 |
|---|---|---|---|---|---|---|
| E-01 |  | 내부 확인 | YYYY-MM-DD |  | F-01 |  |

상태는 `내부 확인`, `외부 확인`, `사용자 제공`, `계산`, `미확인` 중 하나만 사용한다. 계산은 입력값·산식·단위를 모두 기록한다. 미확인 정보는 확정적 문장에 사용하지 않는다.

## 제안서 원고

```markdown
### 원본 항목명
핵심 주장: ...
근거: E-01, E-03
본문: ...
미확인: [[확인 필요: 2025년 확정 매출액, 단위 백만원]]
```

최종 HWPX 이식 시 내부 작업 표시는 제거하되, 해결되지 않은 값을 임의로 채우지 않는다.

## 적대 검토와 미확인 질문

| 심각도 | 위치 | 심사자 반론·문제 | 필요한 근거 | 해결 경로 | 상태 |
|---|---|---|---|---|---|
| 차단 |  |  |  | 사용자 확인 | 열림 |

질문에는 필요한 이유, 들어갈 위치, 허용 형식과 단위를 함께 쓴다.

## 제출 전 점검

- 접수 마감·제출 경로·신청 자격을 최신 원문에서 재확인
- 법인명, 사업자등록번호, 대표자, 연락처 일치
- 매출, 인력, 투자, 특허 수치의 기준일과 증빙 일치
- 본문과 표의 숫자·단위 일치
- 안내 문구와 작성 예시 제거
- 서명·날인·동의 체크 완료
- 페이지·파일 용량·원본 파일 형식 준수
- HWPX 재추출 및 전 페이지 시각 확인
