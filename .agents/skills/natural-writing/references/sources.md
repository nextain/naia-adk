# Reference Sources

- 국립국어원, 「번역투와 국어」 (`https://www.korean.go.kr/nkview/nklife/2012_1/22_0105.pdf`): 한국어 번역투의 소유 표현, 복수 표지, 전치사구 직역과 피동 표현을 다룬 연구 소개 자료.
- 국립국어원, 「한눈에 알아보는 공공언어 바로 쓰기」 (`https://www.korean.go.kr/common/download.do?c_file_name=f595077c-82b4-42a5-8ab6-0c31fef547ff.pdf&file_path=etcData&o_file_name=public-language.pdf`): 문장 호응, 수식 관계, 번역투 개선 기준을 정리한 안내서.
- 국립국어원, 「쉬운 공문서 쓰기 길잡이」 (`https://korean.go.kr/common/download.do?c_file_name=afcf8cc1-ea6a-422d-91b4-d139d4ad7577.pdf&file_path=etcData&o_file_name=%EC%89%AC%EC%9A%B4+%EA%B3%B5%EB%AC%B8%EC%84%9C+%EC%93%B0%EA%B8%B0+%EA%B8%B8%EC%9E%A1%EC%9D%B4%282022%29-%EC%9B%B9%EC%9A%A9_%EC%88%98%EC%A0%952.pdf`): 독자 관점과 문장·문서 구성 기준을 설명한 길잡이.
- 국립국어원 온라인가나다, 겹피동 질의응답 (`https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=317346&searchCondition=&searchKeyword=`): 이중 피동 표현의 판정 기준 설명.
- 김정우, 「번역투의 성격 규명을 위한 다차원적 접근」 (`https://journal.kci.go.kr/kats/archive/articlePdf?artiId=ART001059071`): 외국어 구문과 전치사구가 한국어 문장에 옮겨지는 양상을 분석한 논문.
- DaleSeo/korean-skills — humanizer (`https://github.com/DaleSeo/korean-skills/blob/main/skills/humanizer/SKILL.md`): 한국어 번역투와 AI 문체 유형 및 의미 보존 점검 항목을 정리한 스킬 문서.
- choconyam/humanizer-ko (`https://github.com/choconyam/humanizer-ko`): 한국어·영어 문체 규칙과 선택형 검사 스크립트를 담은 저장소.
- blader/humanizer (`https://github.com/blader/humanizer/blob/main/SKILL.md`): 영어 AI 문체 유형과 교정 원칙을 정리한 스킬 문서.
- Yoon-robin/claude-humanizer (`https://github.com/Yoon-robin/claude-humanizer`): 언어별 참조 문서를 분리해 구성한 문체 점검 스킬.
- hanlint (`https://pypi.org/project/hanlint/0.0.9/`): 마크다운 문서의 한국어 번역투와 이중 피동 등을 검사하는 도구.
- GeulLint (`https://github.com/binibinibin123/geullint`): 한국어 문법·맞춤법·문체 규칙을 검사하는 로컬 CLI 도구.
- Textlint (`https://github.com/textlint/textlint`): 마크다운과 일반 텍스트에 규칙 플러그인을 연결해 쓰는 문장 린터.
- Self-Refine (`https://arxiv.org/abs/2303.17651`): 초안 생성 뒤 자체 피드백과 재작성을 반복하는 방법에 관한 논문.
- When Can LLMs Actually Correct Their Own Mistakes? (`https://aclanthology.org/2024.tacl-1.78/`): 자체 교정의 한계와 외부 피드백 조건을 분석한 논문.
- KatFishNet (`https://arxiv.org/abs/2503.00032`): 한국어 인간 작성문과 생성문의 언어적 특성을 비교한 연구.
